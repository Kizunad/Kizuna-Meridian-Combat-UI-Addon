# Kizuna 经脉战斗 UI

Minecraft 1.20.1 Fabric 附属：`R` 切换战斗架势，架势内 1–0 施放客户端十槽中的已学功法。
v1.1 支持第一人称与独立越肩镜头，架势内默认用 `V` 切换并记忆选择。
架势内显示十槽图标、冷却和不可用状态，缺图时显示文字。

使用、构建、协议、接口需求及验证记录统一维护在 [Wiki](docs/wiki/Home.md)。
本地文件清单和验收结果见 [v1.1 交付记录](docs/wiki/Delivery-v1.1.md) 与 [首版记录](docs/wiki/Delivery.md)。
当前图标栏的依赖、改动与测试见 [图标栏交付](docs/wiki/Delivery-HUD.md)。
