# 使用方法

客户端和服务端均安装本附属、Fabric API 与功法框架；使用 Minecraft 1.20.1、Fabric Loader 0.16.10 以上、Java 17 以上。
本附属不包含具体功法或玩家身体，整合服还须提供功法目录与实体宿主。

## 设置槽位

先由服务端的公开学会命令或宿主逻辑授予功法，再用 `/meridian combat slot` 设置（权限 0，写法见
[Framework 指令页](https://github.com/Kizunad/Kizuna-Meridian-Mod-Framework/wiki/Commands#combat)）：

```text
/meridian combat slot set 1 meridian_basic_techniques:light_step
/meridian combat slot set 10 meridian_basic_techniques:breath
/meridian combat slot clear 1
/meridian combat slot list
```

指令由服务端解析后只发给执行者本人的客户端，槽位仍只写客户端本地文件，服务端不保存；客户端没装本附属时指令失败。

示例 ID 需要实际内容附属提供。`set` 只接收当前服务器已学列表中的完整 ID，补全取服务端最近一次推送给本人的同一列表。
`set` 和 `clear` 的槽号均补全 1–10，并按已输入的数字前缀过滤；子命令使用固定 literal。
同一功法可以占多个槽，仍共用服务端冷却。`list` 在聊天区列出全部十槽，便于完整阅读；操作状态和施放拒绝使用动作栏。
旧槽对应内容被移除或不再已学时保留配置并标失效，按键只提示，不发包。

## 按键

| 操作 | 架势外 | 架势内 |
|---|---|---|
| `R` | 进入架势 | 退出架势 |
| 原版快捷栏 1–9 | 原版 | 施放对应槽，消费原版按下次数 |
| `0` | 无行为 | 施放第十槽 |
| `V` | 无行为 | 切换第一人称/越肩，并保存选择 |
| 原版视角键（默认 F5） | 原版 | 消费按下次数，由 `V` 管理两模式 |
| 滚轮、F、Q | 原版 | 原版 |

1–9 跟随原版快捷栏键位设置；`R`、`0` 和 `V` 在「经脉战斗」按键分类中可改。
进入架势要求存活、非旁观、无打开界面且服务端支持施放通道，不要求学会功法或配置任何槽位。
十槽全空也可按 `R` 直接进入并用 `V` 切视角；空槽按数字键只在动作栏提示「第 N 槽为空」，不发送施放请求。
死亡、旁观、断线自动退出；打开界面保留架势，但暂停施放。
第一人称下，按住移动键施放沿用首版按人物 yaw 合成的移动方向；没有移动输入时发送零，由服务端宿主决定默认方向。

## 两种架势视角

新配置默认第一人称。进入架势会记录此前的原版视角，并切到上次选择的架势模式。
退出架势精确恢复进入前的第一人称、背面第三人称或正面第三人称；死亡、旁观和断线复用此恢复路径。
打开界面保留架势和视角，暂停施放及模式切换，关屏不会把界面内按键补发。

越肩模式中，鼠标直接控制独立镜头，不改变人物真实 yaw/pitch。
WASD 按镜头水平朝向移动，人物按配置速度转向移动方向；转身过程中移动已经沿镜头方向，出招仍沿人物当前朝向。
不按移动键时人物保持原朝向，可用鼠标绕看。实体和原版移动包只包含人物角度，镜头角不发送给服务器。

越肩下的左键近战选中射线、功法目标射线仍从人物眼位沿人物朝向发出，不能用画面中心准星瞄准。
有移动输入的功法请求携带人物当前水平朝向，无输入保持零向量，整合宿主须将零解释为人物默认朝向。
人物俯仰保持进入越肩时的真实 pitch；可切回第一人称调整，再切到越肩。切回第一人称不会把绕看镜头角写回人物。

镜头位于右肩斜上后方。相机中心与八角探测线检查完整偏移段，碰到方块时整段等比拉近，移开遮挡立即恢复距离。
使用原版 VISUAL 方块形状，流体不作为墙。镜头位置不影响人物眼位、攻击距离或目标射线。

## 本地存储

配置路径为游戏目录下的 `config/kizuna-meridian-combat.json`。
多人按 `server:` 加小写地址分档；单人按 `world:` 加实际存档文件夹名分档。
首次进入新档复制上一档，否则十槽为空；最多 64 档，超限淘汰最久未使用档。
服务器别名或端口不同会成为不同档，换电脑须自行复制配置文件。

模式与镜头参数是跨服务器共享的顶层 `view` 对象，切服、复制档案或淘汰档案都不会重置：

```json
"view": {
  "mode": "FIRST_PERSON",
  "shoulder_offset": 0.65,
  "height_offset": 0.35,
  "distance": 3.0,
  "turn_degrees_per_tick": 18.0
}
```

这是配置中的字段片段，不是独立完整文件。`mode` 为 `FIRST_PERSON` 或 `SHOULDER`；
右偏与上偏为 0–4 方块，后退距离为 0.25–8 方块，转身速度为 0.1–180 度/tick，所有值须有限。
正常 20 tick/s 下默认转身速度为 360 度/秒。修改几何与转速须退出游戏后编辑文件，再重启读取。
文件格式升级为 2；首版格式 1 自动使用第一人称默认参数，保留十槽与分档，下次正常保存时迁移。

损坏文件或不支持的版本保留原件，本会话从空配置开始并禁止写回，日志和动作栏各提示一次。
此时命令可调整本次内存配置，并明确提示仅当前会话生效。普通保存失败也会提示会话有效，成功提示不会覆盖故障。
退出游戏后修复或自行备份原文件，再重新启动读取。


## 架势图标栏

架势中在快捷栏上方显示固定十槽，槽号顺序为 1–9、0；退出架势隐藏，F1 隐藏 HUD 时也隐藏。
功法图标按 `presentation.icon_id` 映射到 `assets/<namespace>/textures/gui/technique/<path>.png`。
资源包可以替换图标；没有图标 ID 或找不到 PNG 时显示短名称，不显示紫黑缺失贴图。

灰框「空」表示未绑定；红框与叉号表示未学、内容已移除或当前身体绑定失败；
黑色遮罩和秒数表示冷却，遮罩随本地单调时钟递减。重复绑定同一功法的槽共享冷却表现。
服务器每 5 tick 刷新身体投影，学习事件仍立即排队；网络延迟或服务器暂停可能让显示暂时过期。
图标栏显示身体绑定与冷却的查询结果，不能保证真元、持物、组织占用或承接条件全部满足；
实际按键仍向服务器请求施放，权威拒绝原因继续通过动作栏显示。

受击僵直时，图标栏上方左侧显示「僵直 0.6 秒」，准星对准的实体僵直时右侧显示「目标僵直 0.4 秒」；
灰色静态文字，不做动画，倒数到零即消失。数据来自功法库的 `meridian_technique:stagger` 显示回执，
只在命中开始或延长时下发；离开追踪范围后再进入的实体在下一次命中前不显示。僵直判定和减速都在服务端，
本 HUD 只读不判。
