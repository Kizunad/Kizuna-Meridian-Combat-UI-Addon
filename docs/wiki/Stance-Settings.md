# Combat 姿态设置

入口：Inventory UI 工作区 → Meridian / 设置 → Combat 姿态。功法配置底部“姿态设置”打开同一个窗口。
不新增全局设置快捷键；R 仍切换架势，V 在第一人称与越肩之间切换。

## 范围与视角联动

仅接管当前本地玩家的 Combat 越肩模式。架势外可编辑共享偏好，“调整视角”置灰并解释进入条件。
普通第三人称和第一人称不锁镜头、不自动转身，退出架势仍恢复进入前的原版 F5 视角。

`Lock current view` ON 表示人物与视角联动：鼠标同时转动镜头及人物真实 yaw/pitch，头部随之转动。
人物保持朝向镜头前方，左右移动和后退不再把人物转向移动方向；相机继续跟随人物位置和避障。
OFF 保留当前角度并恢复独立绕看，人物恢复随移动转身。开关持久化，实际角度不持久化。
同时开启 Auto Face Target 时，目标朝向优先，鼠标仍可转动镜头；解除目标后恢复人物与镜头联动。
普通界面和相机编辑期间暂停联动，第一人称及架势外走原有输入路径。

## 相机编辑

透明编辑屏幕显示真实世界、玩家及装备；鼠标保持可见，直接点击保存、取消和恢复默认。
原版重绑定后的前后键调整距离、左右键调整肩偏移、跳跃/潜行键上下移动相机。
调整沿进入时相机局部轴，角度不旋转；相反键抵消，对角归一化，按单调时间推进且限制大帧间隔。

横向与高度 `[-4, 4]` 格，距离 `[0.25, 8]` 格，拒绝非有限数值。
贴墙时正式碰撞路径临时拉近并显示反馈，保存仍使用期望距离。
输入不驱动人物移动、跳跃、潜行、攻击、丢物或功法；重力、受击和世界时间照常推进。
窗口失焦清除编辑按键，恢复焦点后需要新的按下。

预览保存成功立即持久化并返回同一个父页，之后取消父页不会撤销该次相机保存。
取消/Esc 恢复进入参数与角度，保留父页其他草稿。保存失败留在编辑器并允许重试。
死亡、旁观、切维度、换相机实体、断线或架势失效终止预览，不恢复失效会话。

## 自动面向目标

新快捷键默认未绑定，可在设置页或原版“经脉战斗”控制分类设置。
无界面且越肩有效时按键，以实际相机中心射线选择第一个可选实体，受方块遮挡限制。
范围按玩家到实体的三维距离判定，默认 50 格，可设 `[1, 128]`；也受客户端实体追踪距离限制。
再次按键解除；无命中提示“未找到可锁定目标”。不自动攻击、追逐、扩大攻击距离或保证命中。

真实人物 yaw/pitch 以现有转身速度朝向目标，优先于视角联动和移动转身；WASD 与疾跑跳跃仍按镜头水平轴移动。
目标死亡、卸载、移除、换世界或超出半径立即解除；恰在边界仍有效，短暂遮挡不解除。
玩家失效、离开越肩或进入相机编辑也解除。普通界面暂停转身但继续校验失效，关闭后恢复。
HUD 显示名称并遵循隐藏规则，不画透视轮廓，不改变正常攻击射线及服务端校验。

## 草稿与保存

保存统一校验；取消、关闭、Esc 和断线丢弃未提交修改。键位录入时 Esc 只取消录入，
录入 R、V、数字键不触发游戏行为，清除及冲突提示共用原版 KeyMapping。
Combat 偏好与 options 分别报告成功/失败，已成功项不因另一项失败而回滚。
损坏或未知版本配置保留原件且禁止覆盖，详见[配置契约](Contracts.md)。
